# Model Assets

The parametric body and face model assets required by GUAVA-Hand are not
redistributed in this repository.

Please obtain the required assets from their official sources:

- SMPL-X
- MANO
- FLAME

Place them under the corresponding directories:

assets/
├── SMPLX/
├── MANO/
└── FLAME/

Please also refer to the upstream GUAVA setup instructions for the required
filenames and directory structure.

This repository does not redistribute How2Sign data, pretrained GUAVA
checkpoints, tracking outputs, rendered videos, or experiment checkpoints.
